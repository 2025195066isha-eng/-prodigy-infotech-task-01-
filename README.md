# Data Science Task 01 - Population Distribution Visualization

## Overview
This repository contains the solution for **Task-01** of the Data Science internship at **Prodigy InfoTech**. The objective is to create a bar chart or histogram to visualize the distribution of a categorical or continuous variable, such as age or gender in a population dataset.

## Features
* **Continuous Variable Visualization:** Uses a histogram with Kernel Density Estimation (KDE) to display age distribution.
* **Categorical Variable Visualization:** Uses a bar chart (countplot) to illustrate gender distribution.

## Technologies Used
* **Python 3**
* **Pandas**
* **Matplotlib**
* **Seaborn**
